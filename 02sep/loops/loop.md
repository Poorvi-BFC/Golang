## for loop:
for (INITIALIZATION ; CONDITION ; AFTER){}

we can omit any of the section in for loop in Golang. eg:
for (INITIALIZATION ; ; AFTER) {} //WILL SHOW HOW FAR THE MSG CAN GO?

## while loop: 
in golang, there is no specific keyword {while}. instead we write for loop in special conditions and it becomes while loop.

for (CONDITION){
     // do stuff while condition is true.
     AFTER
}
