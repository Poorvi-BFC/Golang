## Assignment: Preallocate Slice for Daily User Counts
Objective: Write a function getDailyUserLimits() that takes a slice of daily user signups ([]int) and returns a slice containing double each day's count ([]int), using make() to preallocate space.

## Instructions:
Create a function named getDailyUserLimits(signups []int) []int.

Inside getDailyUserLimits, preallocate the result slice using make() so it has the same length as signups.

Loop through signups and populate your new slice so that each index contains double the number of signups for that day.

Return the new slice.
