## Concept Overview
Generics allow functions and data structures to accept type parameters enclosed in square brackets [T any], avoiding code duplication for different types (like int, float64, or string).

## Go
func getLast[T any](s []T) T {
    if len(s) == 0 {
        var zero T
        return zero
    }
    return s[len(s)-1]
}
[T any]: Defines T as a generic type parameter that can stand for any Go type.
