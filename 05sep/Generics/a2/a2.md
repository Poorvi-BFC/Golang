## Concept Overview
Sometimes you need a generic function to work only with types that implement specific methods. You can use an interface as a type constraint.

## Go
type lineItem interface {
	GetCost() float64
}

func chargeForLineItem[T lineItem](newItem T, oldItems []T, balance float64) ([]T, float64, error) {
    // T is guaranteed to have a .GetCost() method!
}
By constraining T to lineItem, Go allows you to call newItem.GetCost() safely inside the generic function.
