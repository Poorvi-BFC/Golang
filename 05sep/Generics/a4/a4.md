## Concept Overview
Parametric constraints allow generic interfaces to pass type parameters down to their underlying method definitions.

For instance, a biller[C customer] interface can define a Charge method that accepts a specific type C implementing customer:

## Go
type biller[C customer] interface {
	Charge(customer C, amount float64) bill
	Name() string
}
