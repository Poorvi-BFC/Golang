## Concept Overview
In Go, interfaces can also specify type constraints by listing types separated by the | (OR) operator. The ~ symbol allows matching underlying types (custom types built on base types).

## Go
type Number interface {
    ~int | ~int64 | ~float32 | ~float64
}
This allows you to write generic functions that perform operations like addition or comparison that are only valid on specific primitive types.
