## Concept Overview
The standard library provides sync.RWMutex, which offers fine-grained locking control:

Lock() & Unlock(): Standard exclusive lock for writing. Only one goroutine can hold this lock, blocking all readers and writers.

RLock() & RUnlock(): Shared lock for reading. Multiple goroutines can hold RLock() simultaneously as long as no writer holds Lock().
