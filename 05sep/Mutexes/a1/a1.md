## Concept Overview
A "Mutex (Mutual Exclusion)" allows threads/goroutines to lock access to a shared resource so that only one goroutine can read or write to it at a time.

In Go, mutexes are provided by the sync package:

mux.Lock(): Blocks other goroutines from acquiring the lock until it's released.

mux.Unlock(): Releases the lock so another goroutine can proceed.

Maps in Go are not thread-safe. If multiple goroutines write to a map concurrently, the runtime will panic. Wrapping the map operations inside a mutex lock guarantees safety.
