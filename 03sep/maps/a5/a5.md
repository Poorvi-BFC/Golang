## Concept Overview
Maps can store other maps as their values, creating nested structures like map[rune]map[string]int.

When working with nested maps:
Always initialize the outer map using make().

Before setting a value in an inner map, check if the inner map exists.

If the inner map is nil, initialize it using make() before adding key-value pairs.

## Assignment Question
Complete the getNameCounts function. It takes a slice of strings (names) and returns a nested map map[rune]map[string]int.

The first key is the first character (rune) of each name.

The second key is the name string itself.

The value is the total count of how many times that name appears in the slice.

## For example:
if the input is []string{"billy", "billy", "bob"}, the map will store:
'b' -> "billy" -> 2
'b' -> "bob" -> 1
