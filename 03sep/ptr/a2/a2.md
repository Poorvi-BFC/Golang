## Concept Overview
When a pointer is passed into a function, the function receives a copy of the memory address. Dereferencing that pointer using * allows the function to mutate the original value in the calling scope.

## Assignment Question
Complete the removeProfanity function. It receives a pointer to a message string (message *string).

Check if the string pointed to by message contains "fudge". Replace "fudge" with "f***e".

Check if the string pointed to by message contains "shiz". Replace "shiz" with "s**z".

Check if the string pointed to by message contains "dirty". Replace "dirty" with "d***y".

(Hint: You can use strings.ReplaceAll(*message, "fudge", "f***e") and assign the result back to *message.)
