## Concept Overview
A pointer holds the memory address of a value rather than the value itself.

& Operator (Address-of): Generates a pointer to its operand (e.g., &x gets the memory address of x).

* Operator (Dereference): Accesses or updates the underlying value that a pointer points to (e.g., *p reads/writes the value stored at address p).
