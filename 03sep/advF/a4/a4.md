## Concept Overview
A closure can access and mutate variables declared in its outer (surrounding) scope, even after that outer function has finished executing.

However, it cannot access local variables declared inside another separate function unless those variables were captured or passed to it.
----------------------------------------------------

A closure is a function that references variables from outside its own function body. The function "encloses" these variables, allowing it to access and mutate them even after the outer function has finished executing.
